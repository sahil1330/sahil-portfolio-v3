# 3D avatar slot

The final character file should be saved as `sahil-avatar.glb`.

Preferred delivery:

- Rigged humanoid GLB
- Neutral idle pose plus turn/look, short walk and inspect/point clips
- Meshopt or Draco geometry compression
- KTX2-compressed textures
- 2K textures maximum for the web version
- Approximately 3–5 MB total, preferably smaller

The scroll choreography is already separated from the model, so the procedural mannequin can be replaced without redesigning the page.
